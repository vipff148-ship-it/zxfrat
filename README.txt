📁 Surfaxt RAT - Full Control Android Trojan
Version 2.3.1 | Production Ready

📌 Deskripsi
Surfaxt adalah alat kendali jarak jauh penuh untuk perangkat Android. Dirancang untuk ekfiltrasi data massal, pengambilalihan perangkat, dan pencatatan aktivitas pengguna secara diam-diam. Mendukung mode offline dan online dengan server C2 pribadi.

⚙️ Kemampuan Operasional

· Keylogger global – Merekam semua input teks, termasuk password dan OTP.
· Akses SMS & Kontak – Membaca, menyimpan, dan mengirim ulang semua pesan & kontak.
· Screen Capture & Rekam Suara – Aktivasi jarak jauh melalui perintah C2.
· Lock Perangkat – Mengunci layar target kapan saja.
· Ekfiltrasi Cloud – Mengambil token sesi dari Google, Drive, Gmail, dan lainnya.
· Anti-Uninstall – Mencegah penghapusan melalui notifikasi palsu dan DeviceAdmin.
· Update OTA – APK dapat memperbarui dirinya sendiri dari server.

🔧 Komponen

· core/ – Service utama & aksesibilitas.
· c2-panel/ – Dashboard kontrol berbasis web.
· builder/ – Generator APK custom per target.

📡 Protokol Komunikasi

· WebSocket + HTTP/2 over TLS.
· Domain C2 berganti setiap 48 jam (DNS-over-HTTPS).
